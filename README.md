# 💬 Chatify – Real-Time Chat Application

Chatify is a modern real-time chat application that enables users to communicate instantly with secure authentication and seamless WebSocket-powered messaging.

Built with a scalable full-stack architecture, Chatify delivers fast, responsive, and reliable real-time communication.

## 🧠 How It Works

1. Users register and login securely.
2. Authentication token (JWT) is generated.
3. Users connect via WebSocket.
4. Messages are sent in real-time using Socket.IO.
5. Messages are stored in MongoDB for persistence.
6. Online users are tracked dynamically.
